# 하남시 미사지구 부동산 대시보드

센트럴자이 미사금호부동산 브리핑용 대시보드입니다.

**공개 웹사이트:** https://hong0229.github.io/misa-realty-dashboard/

**Windows 실행 파일:** [최신 버전 내려받기](https://github.com/hong0229/misa-realty-dashboard/releases/latest/download/misa-dashboard.exe) ([릴리스 목록](https://github.com/hong0229/misa-realty-dashboard/releases)). 내려받은 파일을 더블클릭하면 열립니다. API 키가 들어 있지 않아, 키가 없으면 릴리스 기준일의 고정 자료로 열립니다.

## 웹사이트 갱신

공개 사이트는 서버 없이 `docs/` 폴더의 파일로 동작합니다. API 키는 브라우저나 저장소에 올라가지 않습니다.
자료를 새로 반영하려면 이 PC에서 `node scripts/build-pages.js`를 실행한 뒤 커밋하고 올립니다. 공개 사이트에서는 매물을 수정할 수 없고, `data/listings.json`이나 PC 화면에서 수정한 뒤 다시 게시합니다.

## 처음 설치 (저장소에서 받은 경우)

1. [Node.js](https://nodejs.org) 22 이상을 설치합니다.
2. `.env.example`을 `.env`로 복사하고 공공데이터포털·한국부동산원 API 키를 넣습니다.
3. `node server.js`를 실행한 뒤 `http://localhost:8787`을 엽니다. Windows에서는 `시작.bat`을 써도 됩니다.

실행 파일(`.exe`)은 저장소에 포함하지 않습니다. 필요하면 `scripts/build-exe.js` 안내대로 만들 수 있습니다.

단지 좌표와 주변시설 자료는 [OpenStreetMap](https://www.openstreetmap.org/copyright) 기반(ODbL)입니다. 추천 매물은 센트럴자이 미사금호공인중개사사무소가 네이버 부동산에 광고한 미사강변도시 아파트 매물(2026-11-18 확인 기준)입니다. 거래 완료 여부는 사무소에 문의해야 합니다.

## 실행

`미사지구 대시보드.exe`를 더블클릭하면 서버가 켜지고 브라우저가 열립니다. 검은 창을 닫으면 서버가 꺼집니다. Node.js를 따로 설치하지 않아도 됩니다.
이미 켜져 있을 때 다시 실행하면 서버를 또 띄우지 않고 화면만 엽니다.

화면을 다시 만든 뒤에도 실행 파일을 다시 빌드할 필요가 없도록, 실행 파일은 다음 순서로 실행할 폴더를 찾습니다.

1. 실행 파일과 같은 폴더
2. 이 PC의 원래 프로젝트 폴더 (실행 파일만 바탕화면 등에 복사한 경우)
3. 둘 다 없으면 내장된 파일을 `%LOCALAPPDATA%MisaDashboard`에 풀어 실행합니다. 그 폴더에 `.env`가 없으면 빌드할 때 넣은 공개용 고정 자료로 엽니다.

실행 파일에는 API 키가 들어 있지 않습니다. `.env`에 API 키가 있으니 외부에 공유하지 마세요.
지도와 최신 데이터를 받으려면 인터넷 연결이 필요합니다. `시작.bat`은 Node.js가 설치된 PC에서 쓰는 예비 실행 방법입니다.

이 PC에서는 화면이나 데이터를 수정해도 실행 파일을 다시 만들 필요가 없습니다. 다른 PC용 내장 자료를 새로 넣으려면 `node scripts/build-pages.js`로 자료를 갱신한 뒤 `scripts/build-exe.js`로 다시 빌드합니다.

## 단지별 실거래가와 시세

- 단지별 실거래가: 단지·매매/전세/월세·기간(3개월~2년)·평형을 골라 거래 목록과 가격 추이를 봅니다.
- 최근 시세 현황: 단지·평형별 최근 실거래 평균(월세는 중위값)과 전세가율입니다. 호가가 아니라 신고된 실거래 기준입니다.

## 조회 기간과 출력

- 주간(기본 12주), 월간(기본 12개월), 3개월(최근 3개월, 주 단위 그래프), 직접지정(약 6개월까지 주 단위, 더 길면 월 단위 그래프).
- 인쇄: A4 가로로 출력합니다. 인쇄 창에서 대상을 'PDF로 저장'으로 바꾸면 글자를 선택할 수 있는 PDF가 됩니다.
- PDF 저장: 현재 화면을 A4 가로 PDF로 바로 내려받습니다(이미지 방식).

## 수정할 곳

| 내용 | 위치 |
|---|---|
| API 키 | `.env` (브라우저에 노출되지 않습니다. 외부에 공유하지 마세요) |
| 추천 매물 | 화면의 `+ 매물 추가`, 수정, 삭제 버튼 (`data/listings.json`에 저장) |
| 주변 개발계획 | `data/development.json` (기준일과 출처를 함께 수정) |
| 사무소 정보 (상호·대표자·등록번호·주소) | `data/office.json` |
| 로고 | `public/logo.svg` |
| 집계 제외 단지 | `lib/sources.js`의 `EXCLUDED_NAME` |

## 데이터

- 실거래: 국토교통부 아파트 매매·전월세 실거래가 (법정동 망월동·풍산동·선동). 최근 3개월은 12시간마다 갱신합니다.
- 지수·거래량·전세가율·미분양·수급: 한국부동산원 R-ONE. 12시간마다 갱신합니다.
- 단지 좌표·주변시설: OpenStreetMap. `node scripts/build-geo.js`로 다시 수집한 뒤 `node scripts/finalize.js`를 실행합니다.

## 시장 지표 참고

- 월세가격지수와 분양가는 부동산원이 월간으로만 제공합니다. 분양가는 시·도 단위까지만 있어 경기와 수도권을 표시합니다.
- 분양가는 ㎡당 가격을 3.3㎡당으로 환산한 값으로, 전용면적 기준 실거래 평당가와 면적 기준이 다를 수 있어 직접 비교할 때 주의가 필요합니다.
- 1년 변동률은 1년 전 같은 시점 지수와 비교한 상승률입니다.

## 외지인 수요와 공급 시나리오

- 외지인 비율: 한국부동산원 매입자거주지별 아파트매매거래현황(하남시). 단지별·미사지구별 자료는 공개되지 않습니다.
- 공급 시나리오와 전망 문구: `data/outlook.json`에서 수정합니다. 기준일과 출처도 함께 고쳐 주세요.
